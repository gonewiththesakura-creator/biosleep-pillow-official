# BioSleep Atelier | 生物基安睡枕官网

一个为生物基安睡枕打造的高端极简官网原型：大面积留白、克制排版、布料动态、3D 枕头查看与可交互卧室场景。

## 特点

- 极简高端品牌视觉：接近 Apple / BMW 式克制、留白和产品雕塑感
- Three.js 3D 枕头模型：鼠标移动可轻微旋转查看
- 布料/纤维感动态背景：Canvas shader-like 粒子与波纹
- 交互卧室场景：点击 Hotspot 查看材料、承托、睡眠微气候
- 响应式：适配桌面与移动端
- Vite 静态构建，可部署到 Vercel / Netlify / GitHub Pages

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 部署

构建产物位于 `dist/`。
